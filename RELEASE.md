# WPRaffle 1.4.6

Released 11 October 2026.

## Changes

- Lead the private account overview with the next awaiting draw and a direct My tickets action; group lifetime totals and provide a useful empty state.
- Render localized, absolute draw dates with timezone-aware machine-readable values and readable translated price qualifiers.
- Update account styles and add regression coverage for account summaries and draw dates.

## Upgrade

Install the plugin before updating the companion theme. Existing settings and records are preserved. This version introduces no additional database schema changes over 1.4.5. Back up your site, check the update on staging and clear caches after installation.

See [README.md](README.md) for installation and configuration.
